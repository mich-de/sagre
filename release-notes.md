# SagreAI v1.0.0

App Android per tracciare sagre e feste paesane: scatta/carica la foto di una locandina, l'app estrae automaticamente nome, data, luogo e orari tramite OCR + AI (Google Gemini), poi ti permette di salvare l'evento e sincronizzarlo con Google Calendar.

## Funzionalità
- Scansione locandine con estrazione automatica dei dati (OCR ML Kit + Gemini)
- Storico sagre salvate, con vista calendario
- Sincronizzazione eventi su Google Calendar
- Radio Sagra integrata
- Interfaccia Material 3, font Outfit/Inter

## Installazione
Questo è un **build di debug**, non firmato per il Play Store. Per installarlo:
1. Scarica `SagreAI-v1.0.0.apk` qui sotto
2. Sul telefono Android: Impostazioni → Sicurezza → consenti installazione da "origini sconosciute" per l'app che usi per aprire il file (es. browser o file manager)
3. Apri il file APK scaricato e conferma l'installazione

## Requisiti
Android 8.0+ consigliato.
